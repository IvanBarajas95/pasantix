# API REST – Pasantix (Node.js + Express + MySQL)

Arquitectura **MVC**: `routes` → `controllers` → `models` → MySQL. Middlewares de autenticación JWT y manejo de errores.

```bash
npm install
npm run db:init   # crea la base de datos con datos de prueba
npm start         # http://localhost:3000/api
```
Ver [docs/ENDPOINTS.md](docs/ENDPOINTS.md) y la colección `postman/Pasantix_API_Proyecto.postman_collection.json`.
