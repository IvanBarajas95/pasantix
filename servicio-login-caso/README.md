# Servicio web de login (Caso) – Pasantix

Servicio REST que recibe un **usuario** y una **contraseña**:
- Si la autenticación es correcta responde **"Autenticación satisfactoria."**
- Si no, responde **"Error en la autenticación."**

```bash
npm install
npm start   # http://localhost:4000/api
```
Pruebas: importar `postman/Pasantix_Login_Caso.postman_collection.json` en Postman.
Ver [ENDPOINTS.md](ENDPOINTS.md).
